# Photo slots

The files here are **generated placeholder plates, not photographs.** They are
layered SVG scenes — dusk sky, haze, three depth planes, grain — sized to the
exact aspect ratio of each slot so the layout is final and nothing reflows when
real images arrive.

## Dropping in real photography

For each slot below, save the photograph over the placeholder and update the
extension in the markup:

```bash
# 1. add the file
cp ~/shoot/riverbend-highreach.jpg assets/img/photos/demolition.jpg

# 2. point the markup at it (pages/, not the built HTML at the repo root)
grep -rl 'photos/demolition.svg' pages/ | xargs sed -i 's|photos/demolition.svg|photos/demolition.jpg|g'

# 3. rebuild
./tools/build-pages.sh
```

Then **rewrite the `alt` text** to describe the photograph you actually used —
the current alt text describes the placeholder scene, and stale alt text is
worse than none.

Recommended: JPEG or WebP, ~1600px wide (2400px for `hero`), quality ~78,
under 300 KB each. Keep the aspect ratio in the table or re-crop; the CSS
crops with `object-fit: cover`, so a different ratio loses edges rather than
distorting.

## Licensing

Whatever you source, keep proof of licence. If images come from a stock
library, record the source and licence per file in this README so the
provenance survives a handover. Placeholder plates are generated by
`tools/` scripts in-repo and carry no third-party rights.
